Binomial Distribution

The Binomial distribution describes the number of successes in a fixed number of independent trials.

P(X = k) = C(n,k) pk (1-p)n-k

Binomial PMF Calculator

Calculate the probability of getting exactly k successes.

P(X = k) = C(n,k) pk (1-p)n-k

Binomial CDF Calculator

Calculate the cumulative probability up to k successes.

P(X ≤ k) = Σ P(X = x),   x = 0 to k
P(X ≤ 7) = 0.6160

P(X > 7) = 0.3840

P(X ≤ k) means the probability of getting k or fewer successes.
