Exponential Distribution — Cloud Request Inter-arrival Time

Model the waiting time between incoming cloud requests. Default arrival rate: 12 requests per minute.

Exponential probability density

The shaded region shows P(T ≤ t), the probability that the next arrival occurs within the selected threshold.

Memoryless property. If no request has arrived yet, the distribution of the additional wait is unchanged by how long you have already waited. In symbols, P(T > t₂ | T > t₁) = P(T > t₂ − t₁), for t₂ ≥ t₁.

Model assumption: arrivals follow a constant-rate Poisson process. Inter-arrival time is the time between successive request arrivals; it is not server response time or processing latency.

Central Limit Theorem — Warehouse Processing Time

Explore the sampling distribution of the average processing time for random samples.

The Central Limit Theorem says that, under suitable conditions, the sample mean becomes approximately normal as sample size grows. Its standard error is σ/√n. Observations should be independent; n ≥ 30 is a common rule of thumb, not a guarantee.
